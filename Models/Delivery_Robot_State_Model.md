| State_ID | State_Name            | Description                                                               | Entry Condition                                                              | Exit Condition                                                                   |
| -------- | --------------------- | ------------------------------------------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| S1       | **IDLE**              | Robot is at the warehouse and waits for a delivery request.               | Robot is switched on or reaches the warehouse.                               | Delivery request is received.                                                    |
| S2       | **NAVIGATING**        | Robot moves toward the requested destination.                             | A delivery request is received or an obstacle has been successfully avoided. | Obstacle is detected, destination is reached, or battery becomes critically low. |
| S3       | **AVOIDING_OBSTACLE** | Robot temporarily stops normal navigation and avoids a detected obstacle. | An obstacle is detected while navigating.                                    | Obstacle is successfully avoided.                                                |
| S4       | **DELIVERING**        | Robot performs the package delivery at the destination.                   | Robot reaches the requested destination.                                     | Package is successfully delivered.                                               |
| S5       | **RETURNING**         | Robot travels back to the warehouse.                                      | Package is delivered or battery becomes critically low.                      | Robot reaches the warehouse.                                                     |
